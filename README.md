## 📌 Executive Summary

**ROOTEX Multi Speciality Dental and Hair Clinic** is a premier healthcare center in Kestopur, Kolkata, led by **Dr. Aoisik Chattopadhyay** (BDS, Divya Jyoti College of Dental Sciences & Research). The clinic provides painless dentistry (root canal treatments, aligners, implants, smile makeovers) and advanced clinical trichology (PRP, GFC, scalp therapies).

Despite boasting a flawless **5.0 ★ Google Rating across 232+ verified reviews**, the clinic previously relied on third-party portals (Setmore, Justdial, Instagram) without a centralized, branded website. This project provides a turnkey, ultra-modern digital storefront built to convert local searches into confirmed appointments.

## 🚀 Key Features & High-Conversion Mechanisms

### 1. 🕒 Dynamic Live OPD Status Indicator
- Real-time JavaScript engine tracking Kolkata clinic hours:
  - **Morning OPD**: 10:00 AM – 1:00 PM
  - **Sanitation Break**: 1:00 PM – 6:00 PM
  - **Evening OPD**: 6:00 PM – 9:30 PM
- Automatically alerts patients whether the clinic is open now, on afternoon break, or reopening next.

### 2. 🔀 Interactive Dual-Speciality Department Switcher
- Instant toggle between:
  - **Dental Specialities**: Painless RCT, Orthodontics & Aligners, Cosmetic Whitening & Veneers, Implants, Child Dentistry, and Oral Surgery.
  - **Hair & Scalp Solutions**: PRP Therapy, GFC Concentrate, Scalp Trichoscopy, Dandruff Detox, and Density Reversal.
- Each service card features a **"Book This Treatment"** action that pre-selects the treatment in the appointment form.

### 3. 🌟 Direct Google Reviews Integration
- **Direct "Write a Review" Modal Trigger**: Opens Google Search's native review dialogue directly (`#lrd=...,3,,,,`).
- **"Show All 232+ Google Reviews"**: Opens the complete verified patient review list (`#lrd=...,1,,,,`).
- **Interactive Review Invitation Card**: Dedicated callout encouraging recent patients to leave feedback.

### 4. 📲 Automated WhatsApp Appointment Engine
- 60-second booking form with dynamic service population.
- One-click dispatch creating a structured, formatted WhatsApp message sent directly to clinic reception (`+91 94325 35722`):
  ```text
  *Appointment Request - ROOTEX Clinic*
  👤 Patient Name: [Name]
  📞 Phone: [Number]
  🏥 Department: Dental Department / Hair Clinic
  🩺 Service: [Selected Procedure]
  📅 Preferred Date: [Date]
  ⏰ Shift: Morning Shift / Evening Shift
  📝 Notes/Symptoms: [Complaint]
  ```
- Includes direct fallback link to the clinic's existing Setmore booking portal.

### 5. 📸 Clinical Transformation Showcase
- High-resolution comparative case studies for:
  - Full Aesthetic Smile Makeovers (Teeth Whitening + Composite Alignment)
  - Crown Area Hair Density Restoration (6 Months GFC + Scalp Mesotherapy)

### 6. 📱 Mobile-First Sticky Action Dock
- Fixed bottom bar on smartphones with 1-tap touch targets:
  - `[ 📞 Call Doctor ]` (`tel:09432535722`)
  - `[ 💬 WhatsApp ]`
  - `[ 📅 Book Slot ]`

## 💻 How to Run Locally

### Option 1: Python HTTP Server (Recommended)
```powershell
# Navigate to the ROOTEX folder
cd j:\Poulomi_projects\ROOTEX

# Start local server on port 8088
python -m http.server 8088
```
Open **`http://localhost:8088`** in your browser.

### Option 2: VS Code / IDE Live Server
Right-click on `j:\Poulomi_projects\ROOTEX\index.html` and choose **"Open with Live Server"**.

### Option 3: Direct File Opening
Double-click `index.html` to open directly in any browser.
